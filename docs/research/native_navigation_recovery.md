# Native navigation recovery evidence

This bounded recovery covers only the empty-kwargs historical defaults
`swm/TwoRoom-v1`, `swm/Piecewise-v0` (`grid_n=2`) and
`swm/SimplePointMaze-v0` (`show_goal=True`). `TwoRoomTarget`, `PiecewiseZones`,
arbitrary sampled reset variation leaves and the full historical visual-variation
surface remain outside the claim. No readiness or VERIFIED status changes here.

The implementation uses family-local native torch equations and imports no SWM
production code. The oracle is the clean pinned checkout at
`176d54532b3c0a251a4f509b74f2fdacc143a63d`. Seeded reset reproduces Gymnasium's
recursive `Dict.seed` routing with one independently seeded tree per batch lane.
The source has no step RNG. A source `reset(seed=None)` reseeds the variation tree
from fresh external entropy, so full State makes no restored-unseeded-reset replay
claim.

TwoRoom and Piecewise State contains agent and hidden target positions. Target is
required even though the default renderer hides it: observation, goal info,
distance and termination read it. SimplePointMaze State contains a lossless
float64-normalized agent position, reward-goal position, the distinct sampled
agent position used to make cached `info.goal`, and a `state_is_float64` bit.
The bit preserves NumPy's source behavior: accepted float64 actions promote an
unblocked float32 state, while a blocked float64 proposal assigns the prior state
and retains float32. Goal and cached-goal-agent positions remain float32.

Persistent Variation declares every leaf read by transition or termination:
TwoRoom speed/radius/wall/door geometry, Piecewise speed/radius/four zone biases,
and SimplePointMaze speed/radii/wall count/shape/positions. One combined
nondefault case per environment ran 32 exact steps and differed from the
same-seed default trajectory. Reset options are exact for default sampled
positions, `variation=[]`, TwoRoom/Piecewise explicit `state` and `target_state`,
and the explicitly gated dynamics values. Other requested sampled leaves and
unsupported explicit reset values raise instead of being ignored.

SimplePointMaze's canonical private render projection is four columns: agent and
reward goal. `_render_historical_rows(rows)` is a private compatibility path only
for the immutable former two-column hidden-goal renderer corpus. Cached
`info.goal` is regenerated byte-for-byte with Matplotlib Agg from explicit State
and Variation. The pinned SWM lock and CPU oracle used Matplotlib 3.10.9; no other
version has exact-byte evidence yet. Matplotlib is lazy and used only for this
cached task output, while dynamics and public rendering remain native torch.

The CPU gate covers seeds 0/17/42 at batches 1/3, 32 steps, snapshot independence,
candidate-only restoration against an uninterrupted reference, different
histories, hidden-field omission, compact restore refusal, all numeric outputs,
door/wall/zone/collision boundaries, strict success thresholds in float32 and
float64, 257 steps without truncation, nondefault dynamics, full-State private
render identity and render non-mutation. All 18 seed/batch cells had zero error.
The independent reference-only NPZ corpus records typed arrays, per-file SHA-256,
versions, source commit and generator provenance.
