## 4. Public API summary

Canonical, from `STEP_09_AGENT_BRIEFS/WAVE0_CONTRACT.md` and `README.md`:

```python
import stable_envs as snv

env = snv.PushT(num_envs=64, device="cpu")     # classes are canonical
env = snv.make("swm/PushT-v1", device="cpu")   # strings are configs / interop
state = env.reset(seed=0)                      # TensorDict State
pixels = env.render(state)                     # (B,H,W,3) uint8
out = env.step(action)                         # stateful StepResult
nxt = env.transition(state, action)            # functional; env.state untouched
traj = env.unroll(state, actions)              # known actions, not a policy
env.close()                                    # also a context manager

snv.spec("PushT"); snv.list_envs(); snv.set(verbose="INFO")
```

`pack` / `unpack` still emit the Step-8 float32 row. `batch=` warns once and means `num_envs=`.
`StableEnv` / `REGISTRY` / `register` resolve once-per-process with a warning. Nothing from
`render/`, `testing/`, or `interop.py` is advertised at `snv.*` top level.
`stable_envs.testing` is the public measurement library. `stable_envs.rollout` is `snv.sample` /
`BasePolicy`; there is no `env.rollout(policy)`.

## 9. Resource-lifetime status

`stable_envs/render/_resources.py`: `Closeable`, `BoundedCache`, `UseAfterCloseError`. Five backend
objects are `Closeable` (`mjwarp.BatchRenderer`, `nvdiff.Scene`, `nvdiff.BatchRenderer`,
`rendernet._Runner`, `LoadedCorrector`). **No `__del__`.** EGL/GL contexts are **never released**
(`testing/resource_guard.py` incidents). `nvdiff.BatchRenderer.owns_scene` is explicit.
`mjwarp_lightspec._CASTS_CACHE` and `nvdiff.BatchRenderer._ray_cache` are bounded LRU.

Consumer family caches (Fetch, OGBench, RoboCasa, HumanoidBench, MetaWorld, DMC `_TC_CACHE`,
locomotion, Rocket) are `BoundedCache` with `on_evict` calling `release_cached_ctx` /
`close_cached_renderer`. Rocket sets `owns_scene = True`. RoboCasa's corrector cache is
`BoundedCache(4, on_evict=close)`. CPU working-set caches (plates, terrains, RGB atlases,
raycast3d memos, OGBench maze scenes) are the same `BoundedCache` LRU, without a release
callback. EGL contexts are still never released.
