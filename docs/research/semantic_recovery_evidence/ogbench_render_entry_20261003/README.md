# Cube/Scene render-entry profile

Array 6970533 compares nine diagnostic components on an unchanged B64 public
population: State-to-host copy, CUDA/host full validation, projection, public
projection, compact rendering, full-State rendering, preconverted host input,
and host conversion included in full rendering. All image-producing paths must
match the normal full-State CUDA image exactly. Six synchronized samples and
four cProfile summaries distinguish conversion work from rendering. Component
times overlap and must not be added together. This is not an upstream comparison
or a new production implementation. Existing accepted fidelity is unchanged.
