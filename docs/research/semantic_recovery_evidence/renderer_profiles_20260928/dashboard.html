Scope and interpretation

Batch 256 uses prepared inputs and excludes full-State preparation. It repeats up to six real saved poses; it does not represent 256 independent simulator instances. Stages are measured separately and should not be added into an exact cost decomposition. Cube uses GPU mjwarp_fidelity; Scene and Walker use OpenGL; their faster alternatives remain in the full CSV. Symbolic Craftax has no RGB renderer. PushT is diagnostic only. FetchPickAndPlace uses reset-only source States. These profiles do not change rendering quality or semantic acceptance.

Timings use 3–30 warmed samples per probe, with explicit sample counts in the CSV. Every timing outlier is retained. Hover over hardware/backend entries for the host name. Torch traces may not expose external OpenGL/Warp/JAX kernels.
